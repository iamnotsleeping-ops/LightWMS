# P8 · 报表 + 看板 实施计划

## Context

P2–P7 已把账本（`stock_transaction` + `stock_balance`）、采购 / 销售 / 调拨 / 盘点 / 预警、BOM 多版本与对外 7 接口全部落地。系统目前有「作业」能力，但缺「看结果」的窗口：左侧「报表」分组 4 项仍置灰，首页看板只是环境自检占位页。

P8 交付 4 张内部管理报表 + 首页看板（Dashboard），全部基于既有账本与单据表计算，**不新增表、不新增迁移**：

- `report.view` 权限码已在 `0002_rbac_seed.sql` 就位（`sys_admin` / `viewer` / `purchaser` / `salesperson` / `warehouse_keeper` 均已授权）→ 报表接口直接 `requirePermission('report.view')`。
- `export_task` 表虽已预留（`0001_init.sql`），但**本阶段不启用**（见「范围决策」）。
- 看板无独立权限码，「首页看板」菜单本就无需权限 → 接口仅 `authenticate`（登录即可）。

### 已与用户确认的范围决策

1. **导出能力 = 同步 CSV 下载**：报表页「导出」直接返回 `format=csv` 文件，复用 P7 的 CSV 序列化（UTF-8 BOM、不套信封）；**不启用 `export_task` 异步任务**，不做导出中心。
2. **看板包含 4 个板块**：KPI 指标卡、近 30 天出入库趋势、库存预警 Top 清单、单据待办动态。
3. **图表方案 = 引入 ECharts**（新增前端依赖 `echarts`，封装轻量 `EChart.vue`）。

## 关键口径（必须严格遵守）

### 1. 进销存明细账（IF-R1）

按「物料 × 仓库」分组，统计区间 `[dateFrom, dateTo]`：

```
期初数量 opening_qty = Σ(direction × quantity)  where occurred_at < dateFrom
入库数量 in_qty      = Σ(quantity)              where direction = 1  and dateFrom ≤ occurred_at ≤ dateTo
出库数量 out_qty     = Σ(quantity)              where direction = -1 and dateFrom ≤ occurred_at ≤ dateTo
期末数量 closing_qty = opening_qty + in_qty - out_qty
```

金额列同理，用流水 `unit_cost`（分）结转：`opening_amount / in_amount / out_amount / closing_amount`。

- **必须排除 `biz_type = 'status_change'`**：状态转移在同一事务内写「出 + 入」两笔，若计入会让入库、出库两栏同时虚增而净额不变。明细账只反映经营收发（采购入库 / 销售出库 / 采购退货 / 销售退货 / 调拨进出 / 盘盈亏 `adjust`）。
- **日期边界**：`dateTo` 归一到「当日末刻」（`<dateTo>T23:59:59.999Z`），与 P2 的 `asOf` 归一习惯一致；`dateFrom` 取当日 00:00:00。
- **缺省区间**：本月 1 日 ~ 今日（服务端按当日计算）。

### 2. 库存现状表（IF-R2）

复用 `queryStockList`（六项口径：`on_hand / frozen / reserved / in_transit / available / projected`），**增加金额列** `on_hand_amount = Σ(quantity × avg_cost)`（`avg_cost` 取 `stock_balance` 的 `(物料, 仓库)` 维度成本）。

- 指定 `asOf` 时，历史成本不可还原 → `on_hand_amount` 返回 `null` 并写入 `_warnings`（与 P7 历史口径处理一致）。

### 3. 商品收发明细（IF-R3）

复用 `queryTransactions`（流水明细），返回逐笔：`occurred_at / item / warehouse / stock_status / biz_type / biz_no / direction / quantity / unit_cost / amount(=quantity×unit_cost)`。

### 4. 供应商提前期分析（IF-R4）

把 P7 单供应商聚合（`supplierLeadTimeStats`）扩成**全供应商列表**，沿用同一「整单口径」：实际到货时刻取 `stock_transaction` 中 `biz_type='purchase_in'` 按 `biz_id` 的 `MIN/MAX occurred_at`（流水无 `line_no`，只能还原到整单）。

- 列：`supplier_code / supplier_name / order_count / line_count / received_line_count / avg_lead_time_days / min_lead_time_days / max_lead_time_days / avg_promised_lead_time_days / on_time_rate / last_order_date`。
- `lead_time_days = last_received_at − order_date`；`promised_lead_time_days = max(promised_date) − order_date`；`on_time = last_received_at 当日 ≤ max(promised_date)`；`on_time_rate = on_time 单数 / 已到货单数`。

### 5. 首页看板聚合（IF-D1）

`GET /api/dashboard/overview`（登录即可，无额外权限码）一次返回 4 个板块：

- **kpi**（遵循系统参数 `port_stock_as_inventory`，默认排除港口仓）：
  - `on_hand_qty` = Σ `stock_balance.quantity`（`stock_status='available'`）
  - `on_hand_amount` = Σ(`quantity × avg_cost`)（分）
  - `item_count` = 启用物料数
  - `in_transit_qty` = 采购在途（`status ∈ confirmed,partial` 的 `quantity − received_qty − cancelled_qty`）+ 调拨在途（`shipped_qty − received_qty`）
  - `alert_count` = 复用 `queryAlerts({})` 条数
- **trend**：近 30 个自然日（含今日）逐日 `[{ date, in_qty, out_qty }]`，来自流水、**排除 `status_change`**；无流水的日期补 0，保证 30 个点。
- **alerts**：`queryAlerts({})` 取前 10 条（`below_min` 优先），字段同预警页。
- **todos**：`purchase_draft / purchase_pending_inbound / sales_draft / sales_pending_outbound / transfer_in_transit` 单据计数。

## 接口清单（内部，需登录）

| 编号 | 方法与路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| IF-R1 | `GET /api/reports/inventory-ledger` | `report.view` | 进销存明细账（期初/入库/出库/期末，数量+金额） |
| IF-R2 | `GET /api/reports/stock-snapshot` | `report.view` | 库存现状表（六口径 + 金额） |
| IF-R3 | `GET /api/reports/item-movement` | `report.view` | 商品收发明细（流水逐笔） |
| IF-R4 | `GET /api/reports/supplier-lead-time` | `report.view` | 供应商提前期分析（全供应商聚合） |
| IF-D1 | `GET /api/dashboard/overview` | 仅登录 | 看板聚合（kpi / trend / alerts / todos） |

- 全部查询参数用**内部驼峰命名**（`dateFrom` / `dateTo` / `warehouseId` / `productId` / `bizType` / `page` / `pageSize`），与内部业务接口一致（对外 `/api/v1` 的 snake_case 保持不变）。
- 4 张报表均支持 `format=csv` 同步下载（复用 P7 CSV；文件名 `<report>-<时间戳>.csv`；不套信封）。
- 分页沿用 `paginationQuerySchema`（`page` 默认 1、`pageSize` 默认 20、上限 200）。
